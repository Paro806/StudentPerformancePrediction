# StudentPerformancePrediction
Student Performance Prediction using Machine Learning Classifiers

Developed a machine learning project to analyze and predict factors influencing student academic performance using a structured CSV dataset containing demographic, behavioral, and academic attributes such as nationality, grade level, attendance, class participation (hands raised), and study hours. Implemented and compared multiple classification algorithms to identify the most effective model for predicting student grades and understanding performance drivers.

Performed data preprocessing, exploratory data analysis, feature correlation analysis, and model evaluation using metrics such as confusion matrices and accuracy scores. Created visualizations including heatmaps, performance graphs, and statistical charts to clearly demonstrate data patterns, model behavior, and key predictive factors.

This project highlights practical skills in data analysis, machine learning modeling, feature engineering, and data visualization applied to educational analytics.
