# StudentPerformancePrediction
# Student Performance Prediction System

## Project Overview

This project focuses on predicting student academic performance and calculating grades using Machine Learning techniques. The system analyzes student-related data such as academic indicators, behavioral patterns, and other influencing factors to predict performance outcomes and assist in identifying students who may require additional academic support.

The project demonstrates practical skills in data preprocessing, exploratory data analysis (EDA), machine learning modeling, performance evaluation, and data visualization.

---

## Key Features

* Student performance prediction using machine learning models
* Automated grade calculation based on predicted scores
* Exploratory Data Analysis with graphical insights
* Correlation analysis of academic factors
* Model training, evaluation, and comparison
* Data preprocessing and feature engineering pipeline

* Predict student performance and calculate grades
